# IMAD5112 Life Hack Quiz App

## Description
Android app that tests user knowledge of life hacks through True/False questions. Built for IMAD5112 Assignment 2.

## Features
- Welcome screen with app introduction
- 5 Life Hack vs Myth questions 
- Real-time scoring with Logcat logging
- Results screen with personalized feedback
- Comments and error handling per rubric

## How to Run
1. Clone: `git clone https://github.com/mohlalakgopotso442-glitch/IMAD5112-LifeHackApp.git`
2. Open in Android Studio
3. Click Run ▶️
